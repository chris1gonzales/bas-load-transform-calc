0 · Control line & sizing method

Defaults follow the control line: Distech → ECB/ECL 1.3× rule (switches to the ECY rule when you add an ECY controller), Honeywell → 100 VA cap, JCI/Any → flat margin. Controllers use maximum VA from the library. You can change the method at any time.

1 · Transformer

Max loading is a design margin you set (default 80%). Use the transformer nameplate / submittal for the rating; the dropdown lists common sizes only.
